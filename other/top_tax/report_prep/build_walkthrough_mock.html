Start from the stock of unrealized gains. Layer policies in order — each with its static effect, then its behavioral and cross-base response — and watch the bases and the revenue move. The difference between a rate-only package and one that taxes gains at death is the last step you add.

In production each step is an order-stacked model run (policy k's marginal effect given policies 1…k−1), so the last step is exactly the Figure-3-to-Figure-4 difference. Bases hold fixed positions so the eye tracks what moves; the dashed outline on a revenue bar is the static "ask," the solid fill is what's collected after behavior.
